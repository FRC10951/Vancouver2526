# `frc.robot` package — file guide

This table summarizes what each Java source file under `frc/robot` (including `frc.robot.util`) does and what teams usually change. **IO PID** is documented in [`docs/IO_PID.md`](../../../../docs/IO_PID.md) (repo root `docs/`).


| File                                | What it does                                                                                                                                                                                                                                                                | Common modifications                                                                                                                                                                                                                                                                                                       |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Main.java`                         | JVM entry point: calls `RobotBase.startRobot(Robot::new)` so WPILib boots the `Robot` class.                                                                                                                                                                                | Almost never edited except to point `startRobot` at a different main robot class if you rename or replace `Robot`.                                                                                                                                                                                                         |
| `Robot.java`                        | Extends `TimedRobot`: creates `RobotContainer` in `robotInit()`, runs the command scheduler every loop, schedules autonomous in `autonomousInit()`, cancels auto when teleop starts, clears commands in test mode, and publishes CAN IDs to the console and SmartDashboard. | Add `disabledInit` / `disabledPeriodic` for LEDs or logging; extend `simulationPeriodic()` for sim-specific behavior; rarely, add global lifecycle hooks. Avoid putting binding logic here—keep that in `RobotContainer`.                                                                                                  |
| `RobotContainer.java`               | Wires the robot together: constructs subsystems, Xbox controllers, default commands, button/trigger bindings, `SendableChooser` auto options, the main `autonomousCommand()` sequence, and `getAutonomousCommand()` (alliance + station vs. dashboard chooser).             | **Most edited file for behavior:** change controller layout (`configureBindings`), add/remove auto routines and chooser options, edit `autonomousCommand()` steps (times, speeds, parallel groups), implement per-station methods (`autonomousRedStation1` … `autonomousBlueStation3`), add subsystems or helper commands. |
| `Constants.java`                    | Single place for CAN IDs, current limits, wheel/gear geometry, `DRIVE_QUADRATURE_ENCODERS_WIRED`, drive scaling and deadband, shooter/intake **PID + feedforward** gains and RPM targets, `AutoConstants` (timed main auto), and `getCanIdsList()` for startup logging.       | Tune IDs and limits after wiring changes; drive encoder flag; `AutoConstants`; IO gains per `docs/IO_PID.md`; constants editor (IO / Shooter tab) for most IO PID fields.                                                                                                                                                  |
| `subsystems/CANDriveSubsystem.java` | Differential drive on four Spark MAX (leader/follower per side): arcade/tank/voltage drive, optional encoder distance/velocity when `DRIVE_QUADRATURE_ENCODERS_WIRED` is true, SmartDashboard line when false, and `commandIntakeWiggle` for shooting.                         | Invert/follower setup; when encoders exist, tune `WHEEL_DIAMETER_METERS` / `GEAR_RATIO`; enable sim hooks if needed.                                                                                                                                                                                                       |
| `subsystems/IoSubsystem.java`       | “Fuel” stack: flywheel and intake use **velocity PID + feedforward** (`RpmPidVelocityController`); loader is open-loop; commands for idle, intake, launch variants, eject, reverse/clear, auton intake, etc.                                                                | Adjust gating and command structure; tune PID/FF in `Constants.IoConstants`; see `docs/IO_PID.md`; change `IoCanIdGroup` for alternate wiring.                                                                                                                                                                              |
| `util/RpmPidVelocityController.java` | Shared **RPM → rps** velocity loop: WPILib `PIDController` + `SimpleMotorFeedforward`, spin-up open-loop, integrator reset, output clamp.                                                                                                                                   | Rarely edited; behavior and tuning are documented in `docs/IO_PID.md`.                                                                                                                                                                                                                                                    |
| `commands/Drive.java`               | Default teleop command: split arcade from the driver Xbox controller (left Y forward/back, right X rotate) with deadband and scaling.                                                                                                                                       | Change stick mapping (e.g. single stick arcade, tank), curvature drive, squaring inputs, or slow-mode / turbo when you add buttons.                                                                                                                                                                                        |
| `commands/AutoDrive.java`           | Open-loop autonomous: holds fixed arcade forward and rotation every tick until interrupted; duration is usually set with `.withTimeout(...)` in the container.                                                                                                              | Change speeds/curvature passed from `RobotContainer` or `AutoConstants`; rarely needs internal edits unless you add safety limits or logging.                                                                                                                                                                            |
